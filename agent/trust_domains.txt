# trust_domains.txt — Domain-Vertrauensliste fuer die Web-Gegenpruefung des Agenten.
# =============================================================================
# Format pro Zeile:   domain  [tier]  [topics]
#   tier   = trusted | low          (Default: trusted)
#   topics = optionale Themen, kommagetrennt; Default '*' = alle Themen.
#            Eine [vertrauenswuerdig·THEMA]-Quelle zaehlt VOLL nur, wenn THEMA zur
#            Frage passt; sonst wie neutral. '*' gilt fuer alle Fragen.
# domain:
#   - Subdomains matchen automatisch:  gv.at  -> ris.bka.gv.at
#   - '*.xy.com' ist gleichbedeutend mit 'xy.com' (deckt Domain + ALLE Subdomains).
#   - Spezifischster (laengster) Treffer gewinnt.
# '#' = Kommentar.
#
# Pflege: Datei editieren -> 'docker compose up -d --force-recreate agent'.
#   Schnell ohne Datei-Edit: .env  TRUST_DOMAINS=... / LOW_TRUST_DOMAINS=...  (Thema '*').
# Themen-Beispiele: recht, sozialversicherung, gesundheit, statistik, wirtschaft, technik
