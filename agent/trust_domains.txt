# trust_domains.txt — Domain-Vertrauensliste fuer die Web-Gegenpruefung des Agenten.
# =============================================================================
# Format pro Zeile:   domain [tier]      tier = trusted | low   (Default: trusted)
# '#' = Kommentar. Subdomains matchen den Parent automatisch (gv.at -> ris.bka.gv.at).
#
# Wirkung: jede Web-Quelle wird in der Gegenpruefung als [vertrauenswuerdig] /
# [niedrig] / (neutral) markiert. Die Beleg-Quote gewichtet vertrauenswuerdige
# Quellen STARK, niedrige schwach -> [BESTAETIGT] braucht vertrauenswuerdige Stuetze.
#
# Pflege:
#  - Datei editieren -> 'docker compose up -d --force-recreate agent' (Reload beim Start).
#  - Schnell-Ergaenzung ohne Datei: .env  TRUST_DOMAINS=a.at,b.eu / LOW_TRUST_DOMAINS=c.com
